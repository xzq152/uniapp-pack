把你的品牌资源放进本目录，打包时会替换掉 SDK 模板里的同名文件：

| 文件名      | 作用            | 建议尺寸/说明                          |
|------------|-----------------|----------------------------------------|
| `icon.png` | 应用图标        | 建议 512×512，纯位图（不要 nine-patch） |
| `splash.png`| 启动图（闪屏） | 建议 1080×1920 或使用 .9.png           |
| `push.png` | 通知栏小图标    | 建议 96×96，白色剪影 + 透明背景        |

没有放文件就保持 SDK 模板自带的资源。

> 需要更细的控制（不同分辨率、logo、开屏页 UI）时，往 `config/res/` 里放完整的
> res 目录结构即可（如 `res/drawable-xxhdpi/...`、`res/values/styles.xml`），
> 会被整体覆盖进 `app/src/main/res/`。
