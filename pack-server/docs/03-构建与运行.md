# 03 · 构建与运行

## 顺序不能反：先镜像，后服务

服务只是编排器，真正干活的是镜像。

### 1. 构建打包镜像

```bash
cd android-builder
./build-image.sh                 # 默认 tag: uniapp-android-builder:latest
./build-image.sh -t my-img:1.0   # 自定义 tag（服务端用 IMAGE 环境变量指定）
```

- 首次约 10~20 分钟（下载 Android SDK / Node / Gradle 依赖）
- 改了 `docker/entrypoint.sh` 或 `Dockerfile` 后**必须重新构建**，并且**重启一次容器**（见 06-踩坑）
- DCloud 离线 SDK 放在 `android-builder/sdk/`（zip），构建时会被烤进镜像

### 2. 构建服务（含前端）

Windows 双击 `pack-server/build.bat`，等价于：

```bash
cd web && npm install && npm run build   # 产出 web/dist
cd ..
go build -o uniapp-pack-server.exe .     # go:embed 把 dist 打进去
go build -ldflags "-H=windowsgui -s -w" -o 启动服务.exe ./cmd/launcher
go build -ldflags "-H=windowsgui -s -w" -o 停止服务.exe ./cmd/stopper
```

> **构建前先停止服务**（`停止服务.exe`），否则 exe 被占用会 `Access is denied`。

只改 Go 代码时，不用跑 npm：

```bash
go build -o uniapp-pack-server.exe .
```

### 3. 前端开发模式（热更新）

```bash
cd web
npm run dev     # http://localhost:5173，/api 与 /d 已代理到 8080
```

改完记得跑一次 `npm run build`，否则嵌入的还是旧页面。

## 运行方式

### 日常：托盘常驻（推荐）

双击 `启动服务.exe`：
- 不弹黑窗口，服务在后台跑
- 右下角托盘出现**绿色 Android 机器人头**图标
- 启动时气泡提示（带局域网地址），几秒自动消失
- **双击图标** = 打开打包页面
- **右键菜单**：

| 菜单项 | 行为 |
|---|---|
| （灰字）状态 | `服务运行中/未运行 · 打包环境运行中/已停止` |
| 打开打包页面 | 打开 http://127.0.0.1:8080 |
| 重新启动服务 | 杀掉再拉起服务进程 |
| 停止打包环境（仅容器） | `docker stop uniapp-pack-runtime`，服务继续跑 |
| **停止服务并停止镜像** | 先停容器，再结束服务和托盘 |
| 仅停止服务（保留镜像） | 只结束服务和托盘 |

启动参数：

| 参数 | 作用 |
|---|---|
| `/quiet` | 不弹气泡（计划任务用） |
| `/open` | 启动完成后打开页面；**已在运行时直接开页面不弹框** |

**单实例保护**：托盘宿主用 `Local\uniapp-pack-tray` 互斥量，重复双击不会再起第二个；
启动前还会 `GET /api/env` 探活——端口被**别的程序**占用时会明确报错，而不是误判"已运行"。

双击 `停止服务.exe`：优雅关闭（清托盘图标 + 结束服务），弹提示。
加 `/image` 连打包容器一起停：`停止服务.exe /image`。

### 桌面快捷方式

`桌面\uni-app 安卓打包.lnk`：

| 属性 | 值 |
|---|---|
| 目标 | `D:\uniapp-pack-go\启动服务.exe` |
| 参数 | `/open` |
| 起始位置 | `D:\uniapp-pack-go` |
| 图标 | `D:\uniapp-pack-go\cmd\launcher\tray.ico` |

双击 = 启动服务（已在运行则跳过）+ 打开页面。服务没起来时会先等端口就绪再开浏览器，
所以不会出现"点了打不开"的情况。

### 调试：前台运行

双击 `start.bat`（或直接 `./uniapp-pack-server.exe`），会打印局域网地址和实时日志。
关窗口即停服务。

### 开机自启（可选，当前未启用）

服务已注册计划任务 `uniapp-pack-server`（动作 = `启动服务.exe /quiet`），但目前**没有触发器**。
需要登录即启的话：

```powershell
$dir = "D:\uniapp-pack-go"
$trigger = New-ScheduledTaskTrigger -AtLogOn
$act = New-ScheduledTaskAction -Execute "$dir\启动服务.exe" -Argument "/quiet" -WorkingDirectory $dir
Register-ScheduledTask -TaskName "uniapp-pack-server" -Action $act -Trigger $trigger -Force
```

常用命令：

```powershell
Start-ScheduledTask  -TaskName uniapp-pack-server
Stop-ScheduledTask   -TaskName uniapp-pack-server
(Get-ScheduledTask uniapp-pack-server).State
```

## 端口与访问

| 项 | 值 |
|---|---|
| 监听端口 | `8080`（`PORT` 可改） |
| 本机地址 | <http://127.0.0.1:8080> |
| 局域网地址 | 启动时打印，或 `ipconfig` 看 IPv4，形如 `http://192.168.1.23:8080` |
| 防火墙 | 其他电脑打不开时，放行 8080 入站 |

桌面快捷方式 `uni-app 安卓打包.url` 指向本机地址（图标用的是托盘那枚机器人头）。
注意它只负责打开页面，不负责启动服务——服务没起会打不开，先双击 `启动服务.exe`。

## 上传资源包的两种方式

| 方式 | 适用 | 说明 |
|---|---|---|
| **选择 zip** | HBuilderX → 发行 → 原生 App-本地打包 → 生成资源包 | 得到一个 `__UNI__XXXX.zip` |
| **选择文件夹** | 同上，但导出的是目录 | 浏览器按 `webkitdirectory` 上传，服务端还原目录树，打包时压成 zip 送容器 |

两种方式的解析结果一致（都会读 `manifest.json` 自动填 appid / 应用名 / 版本）。
选文件夹时要选**包含 www 的那一层**，多套一层会导致容器里找不到 `www`。
