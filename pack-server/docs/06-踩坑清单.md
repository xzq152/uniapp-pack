# 06 · 踩坑清单

按"踩过的顺序"记，每条都带**现象 → 原因 → 正确做法**。改这块代码前建议先扫一遍。

---

## 1. 改了 entrypoint.sh 只重建镜像，行为没变

**现象**：日志里没有新加的逻辑（比如没有"渠道标记"行），产物数量也不对。
**原因**：服务用 `docker exec` 在**已存在的容器**里跑脚本，容器文件系统来自创建时的旧镜像。
**做法**：重建镜像后必须 **重启容器**：

```bash
curl -X POST http://127.0.0.1:8080/api/runtime/restart
# 或页面上点「重建」
```

## 2. 修改 .bat 后脚本报 `'%D' 不是内部或外部命令`

**原因**：`.bat` 是 **UTF-8 + LF** 换行，cmd 按本地码页 936 解析时把括号块切碎了。
**做法**：`.bat` 必须是 **GBK 编码 + CRLF 换行**。用 `chcp 65001` + UTF-8 反而更容易炸，别用。

```powershell
$gbk = [System.Text.Encoding]::GetEncoding(936)
$txt = [System.IO.File]::ReadAllText($f, [Text.Encoding]::UTF8) -replace "`r`n","`n" -replace "`n","`r`n"
[System.IO.File]::WriteAllText($f, $txt, $gbk)
```

## 3. 托盘图标一直是系统默认的"小窗口"图标

**现象**：`Shell_NotifyIcon` 返回成功，但托盘显示的是 Windows 默认程序图标。
**原因**：`CreateIconFromResourceEx` 需要的是**单张位图（RT_ICON）**，直接喂整个 `.ico` 文件
（ICONDIR + 目录项 + 数据）会返回 0，代码静默退到 `IDI_APPLICATION`。
**做法**：把 `.ico` 写到临时文件，用 **`LoadImage`**（`LR_LOADFROMFILE` + `SM_CXSMICON`）加载：

```go
size, _, _ := pGetSystemMetrics.Call(49) // SM_CXSMICON
h, _, _ := pLoadImageW.Call(0, uintptr(unsafe.Pointer(pathPtr)), 1, size, size, 0x10)
```

**验证**：`Shell_NotifyIcon` 成功 ≠ 图标正确。用 `GetIconInfo` + `GetDIBits` 把像素读回来，
中心像素应是 `RGBA(61,220,132,255)`（#3DDC84）。

## 4. 用 Chrome 无头模式把 SVG 转 PNG，结果是空白

**现象**：`chrome --screenshot=x.png x.svg` 出来几乎全白；窗口设 128×128 更是什么都没有。
**原因**：直接截图 SVG 文件不渲染；且 Chrome 有最小窗口尺寸，128 宽度会被裁。
**做法**：套一层 HTML，用 `<img src="x.svg" width="256">`，窗口给 **256×256**，
加 `--default-background-color=00000000` 拿到透明背景：

```bash
chrome --headless=new --window-size=256,256 \
       --default-background-color=00000000 \
       --screenshot=out.png file:///c:/temp/icon.html
```

## 5. 页面开着 SSE 时，无头浏览器截图超时

**原因**：`--virtual-time-budget` 要等"网络空闲"，SSE 长连接永远不空闲。
**做法**：验证时用一个不存在的 job（`?job=nope`）只渲染静态结构，或先关流。

## 6. Git Bash 里 `docker run --entrypoint /bin/bash` 报路径不存在

**现象**：`exec: "D:/Program Files/.../usr/bin/bash": no such file`
**原因**：MSYS 把 `/bin/bash` 当成本地路径转换了。
**做法**：命令前加 `export MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL='*'`。

## 7. 用 python/sed 批量改代码后"改了但没生效"

**现象**：`str.replace()` 的锚文本缩进/换行对不上，静默什么也没改，还看不出来。
**做法**：所有脚本化替换**必须带断言**，改完再 `grep`/回读确认：

```python
assert old in s, "锚点未命中"   # 不命中直接报错
s = s.replace(old, new)
```

## 8. 迁移目录时把 junction 里的数据一起删了

**现象**：旧目录下的 `data` 是指向 D 盘的 junction，`rm -rf`（或 robocopy 递归）会把目标内容算进去。
**做法**：
- 复制用 `robocopy /E /XJ`（排除 junction）
- 删旧目录前先删 junction（PowerShell `(Get-Item $link -Force).Delete()`，只删链接）
- 对比文件数时要**排除 data**，否则永远差几十个

## 9. 计划任务/Start-Process 起的服务，会话结束就死

**原因**：通过工具/子进程启动的进程可能挂在父进程的 Job Object 里，父会话退出就被回收。
**做法**：用计划任务托管（`Register-ScheduledTask` + `Start-ScheduledTask`），
进程归属 Task Scheduler，不随终端退出。WMI `Win32_Process.Create` 会被安全策略拦，别试。

---

## 10. 打包成功但真机启动报「appkey 未配置或配置错误」

**原因**：DCloud 离线打包的 appkey 绑定 **appid + 包名 + 证书**，三者任一变了都要重新申请。
**做法**：`AndroidManifest.xml` 的 `dcloud_appkey` 必须与当前组合匹配；
页面表单里「离线打包 appkey」是必填项，历史 appid 会自动回填（`data/appkeys.json`）。

---

## 11. 自定义启动图变形

**原因**：位图被 runtime 整图拉伸铺满屏幕，比例不一致就变形。
**做法**：转 `.9.png`（内容区锁定、背景拉伸）。但**全出血**设计（内容铺满整图）没有可锁定的纯色区，
仍会整体缩放——设计时用「纯色底 + 居中 logo」。不传启动图则用 runtime 原生通用启动页，永不变形。

---

## 12. 多渠道构建时间/磁盘超预期

- 时间：首个渠道 ~50s，之后每个 ~35s（串行，不并发）
- 磁盘：每渠道 ~50MB；保留 5 次构建 → 6 渠道最多约 1.5GB
- 清理按「构建次数」，不是按文件数

要降成本可以调 `KEEP_APK=2`，或只保留常用渠道。

## 13. 想用脚本建 .lnk，被安全策略拦了

**现象**：用 CreateObject / New-Object 之类的方式实例化脚本宿主对象，会直接报
"COM object instantiation can run arbitrary code"，整条命令被拒。
**做法**：写了个一次性 Go 工具直接走 COM：`CoCreateInstance(CLSID_ShellLink)` →
`IShellLinkW::SetPath/SetArguments/SetWorkingDirectory/SetIconLocation` →
`QueryInterface(IPersistFile)` → `Save`。
vtable 调用用 `syscall.SyscallN`（方法索引：SetPath=20、SetArguments=11、
SetWorkingDirectory=9、SetIconLocation=17、Save=6）。
生成的 .lnk 里字符串是 **UTF-16LE**，校验时别用 ANSI 去找。

## 14. 双击快捷方式"没反应"

先分清两件事：
1. **服务有没有起来** —— 看进程 / `Get-NetTCPConnection -LocalPort 8080`
2. **浏览器有没有开** —— `ShellExecuteW` 返回 >32 就算成功，浏览器可能复用已有窗口或后台打开

排查顺序：`启动服务.exe /open` 手动跑一次 → 看托盘图标是否出现 → 再看页面。
