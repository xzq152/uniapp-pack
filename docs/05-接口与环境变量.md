# 05 · 接口与环境变量

## HTTP 接口

除 `/api/login`、`/api/logout`、静态资源外，设置了 `ACCESS_PASSWORD` 时都需要登录态。

### 上传与打包

| 方法 | 路径 | 说明 |
|---|---|---|
| `PUT` | `/api/upload?name=<文件名>` | 上传 zip（请求体为裸字节流，非 multipart） |
| `PUT` | `/api/upload-folder?name=<目录名>` | 上传文件夹（`#F 路径\n大小\n内容` 流式格式） |
| `PUT` | `/api/icon` | 上传应用图标（png） |
| `PUT` | `/api/splash?name=<文件名>` | 上传启动图（png 或 .9.png） |
| `POST` | `/api/build` | 创建打包任务 |
| `GET` | `/api/jobs` | 任务列表（不含日志） |
| `GET` | `/api/jobs/{id}/events` | **SSE** 实时进度与日志 |
| `GET` | `/api/jobs/{id}/log` | 纯文本日志（可下载） |
| `DELETE` | `/api/jobs/{id}` | 移入回收站 |
| `POST` | `/api/jobs/{id}/retry` | 同参数重试（需原包仍在） |
| `GET` | `/api/jobs/{id}/zip` | **把该记录下所有 APK 打成一个 zip 下载** |

`POST /api/build` 请求体：

```json
{
  "uploadId": "u1793...",
  "appId": "__UNI__6744715",
  "appName": "容通助手",
  "package": "com.rongtong2024.app",
  "versionName": "2.3.1",
  "versionCode": "231",
  "appKey": "3b16cd06...",
  "keystore": "auto",
  "icon": "",
  "splash": "",
  "channels": ["huawei", "honor", "xiaomi"]
}
```

### 环境（Docker）

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/runtime` | 状态：`dockerOk / imageOk / running / dockerMem` |
| `POST` | `/api/runtime/start` | 启动容器 |
| `POST` | `/api/runtime/stop` | 停止容器 |
| `POST` | `/api/runtime/restart` | **重建容器**（改了镜像必须调这个） |
| `GET` | `/api/env` | 镜像名、内存、gradle 参数、`keepJobs`、`keepApks` |

### 证书 / 回收站 / 其它

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/keystores` | 证书列表 |
| `PUT` | `/api/keystore` | 上传证书 |
| `DELETE` | `/api/keystores/{id}` | 删除证书 |
| `GET` | `/api/trash` | 回收站列表 |
| `POST` | `/api/trash/{id}/restore` | 恢复 |
| `DELETE` | `/api/trash/{id}` | 彻底删除 |
| `GET` | `/api/appkey?appId=xxx` | 查历史 appkey |
| `GET` / `HEAD` | `/d/{jobId}/{文件名}` | 下载单个产物（支持 Range） |
| `POST` | `/api/login` / `/api/logout` | 口令登录 / 登出 |

## 环境变量

### 服务端（pack-server）

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `8080` | 监听端口 |
| `DATA_DIR` | `<exe目录>/data` | 数据目录，建议指到大盘 |
| `IMAGE` | `uniapp-android-builder:latest` | 打包镜像 tag |
| `ACCESS_PASSWORD` | 空 | 访问口令，设了就需登录；空 = 局域网免登录 |
| `KEEP_APK` | `5` | 只保留最近几次构建的 APK |
| `KEEP_JOBS` | `20` | 记录只保留最近多少条 |
| `USE_CN_MIRROR` | `1` | 容器内 Gradle 走国内镜像 |
| `GRADLE_EXTRA_ARGS` | 空 | 追加给 gradlew 的参数，如 `--offline` |
| `GRADLE_VOLUME` | `uniapp_gradle_cache` | Gradle 缓存卷名（加速二次构建） |
| `PNPM_VOLUME` | `uniapp_pnpm_store` | pnpm store 卷名（源码编译模式用） |

### 容器内（entrypoint.sh，一般不用手改）

`APP_ID` `APP_NAME` `APP_PACKAGE` `APP_VERSION_NAME` `APP_VERSION_CODE`
`KEYSTORE_FILE` `STORE_PASSWORD` `KEY_ALIAS` `KEY_PASSWORD`
`APP_KEY` `CHANNELS` `SPLASH_BG` `SPLASH_HEIGHT` `USE_CN_MIRROR` `GRADLE_EXTRA_ARGS`

其中 `CHANNELS="huawei,xiaomi"` 是渠道列表，空表示只打通用包。

## 默认端口 / 路径速查

| 项 | 值 |
|---|---|
| 服务端口 | 8080 |
| 数据目录 | `D:\uniapp-pack-go\data`（本机） |
| 产物目录 | `data/outputs/<jobId>/` |
| 镜像 | `uniapp-android-builder:latest`（约 3GB） |
| 容器名 | `uniapp-pack-runtime` |
| Gradle 缓存卷 | `uniapp_gradle_cache` |
| 计划任务 | `uniapp-pack-server` |
