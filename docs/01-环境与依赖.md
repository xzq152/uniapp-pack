# 01 · 环境与依赖

整套东西分**宿主环境**和**容器内环境**两层。宿主只需要三样：Docker、Go、Node。

---

## 宿主环境（Windows 开发机）

| 软件 | 版本要求 | 本机实测 | 用途 | 验证命令 |
|---|---|---|---|---|
| Docker Desktop | 4.x（WSL2 后端） | 29.9.2 | 跑打包容器 | `docker info` |
| Go | 1.22+ | 1.27 | 编译服务与启动器 | `go version` |
| Node.js | 18+ | 22.22 | 构建前端（Vite） | `node -v` |
| 浏览器 | Chrome / Edge | — | 上传文件夹需要 `webkitdirectory` | — |

> **Docker 资源**：建议内存 ≥ 6GB（实测分配 7.8GB）。构建时 Gradle 峰值吃 3~4GB，
> 内存给小了会 OOM 或编译超时。在 Docker Desktop → Settings → Resources 里调。

### 磁盘规划（重要）

| 内容 | 大小 | 说明 |
|---|---|---|
| Docker 虚拟磁盘（vhdx） | 10~27GB | 镜像 + Gradle 缓存，**建议放在非系统盘** |
| 打包镜像本身 | ~3GB | `uniapp-android-builder:latest` |
| 单个 APK 产物 | ~50MB | 每渠道一个，按「最近 5 次构建」保留 |
| 上传资源包 | ~20MB/次 | **构建成功后立即删除** |

Docker Desktop 迁移镜像盘：Settings → Resources → Advanced → **Disk image location** 改到 D 盘，
改之前要退出 Docker 并 `wsl --shutdown`，否则会提示"文件被占用"。

## 容器内环境（由镜像提供，不用自己装）

`android-builder/Dockerfile` 构建出的 `uniapp-android-builder:latest` 内含：

| 组件 | 版本 | 说明 |
|---|---|---|
| 基础镜像 | `eclipse-temurin:17-jdk-jammy` | JDK 17（老 SDK 可开 `WITH_JDK11=true`） |
| Android SDK | platform 33/34/35 | commandline-tools + platform + build-tools |
| build-tools | 34.0.0 / 35.0.0 | 含 `aapt2` / `apksigner` |
| Node / pnpm | 20.19.0 / 9.15.4 | 源码编译模式才用得到 |
| Gradle | 由 DCloud 模板自带 wrapper | 首次构建会拉依赖，之后走缓存卷 |
| DCloud 离线 SDK | 放在 `android-builder/sdk/` | 构建镜像时烤进去，不入仓库 |

**DCloud 离线 SDK 需要自己下载**（DCloud 官网 → 离线打包 SDK → Android 版 zip），
放到 `android-builder/sdk/` 目录后再构建镜像。没有它镜像照样能构建成功，但打包时会缺模板。

## 自检清单

```bash
docker info --format '{{.ServerVersion}} {{.DockerRootDir}}'   # 引擎在跑
docker images | grep uniapp-android-builder                     # 镜像存在
go version                                                     # Go 可用
node -v && npm -v                                              # 前端可构建
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8080 # 服务在跑（应为 200）
```

服务自身还提供环境检测接口，页面顶栏那个状态胶囊就是它的可视化：

```bash
curl -s http://127.0.0.1:8080/api/runtime
# {"dockerOk":true,"exists":true,"running":true,"imageOk":true,"dockerMem":"7.8 GB",...}
```

## 常见依赖问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面显示「未连接 Docker」 | Docker Desktop 没启动 / WSL 没起来 | 启动 Docker Desktop，等鲸鱼图标变绿 |
| `docker: command not found` | Docker 未加入 PATH | 重开终端，或检查 Docker Desktop 安装 |
| 构建卡在 `Downloading gradle-*.zip` | 依赖下载慢 | 确认 `USE_CN_MIRROR=1`（默认开），容器会挂 `init.gradle` 用国内镜像 |
| 构建报 `compileSdk 35 not found` | SDK 组件缺失 | entrypoint 会自动补装，也可手动调大 `ANDROID_PLATFORMS` 重建镜像 |
| 前端构建 OOM | Node 内存不足 | `set NODE_OPTIONS=--max-old-space-size=4096` 后再 build |
